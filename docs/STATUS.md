## 정체성

**지라 클론이 아니라 자체 ALM 제품.** 지라의 검증된 구조(전역 사이드바·프로젝트 뷰 탭·
보드/백로그 모델)를 따르되, ALM 고유 편의를 얹는다. 코드도 `src/features/alm`.

### ALM 특색 (지라 대비 개선)

| 특색 | 위치 | 요지 |
|---|---|---|
| 한국어 스마트 검색 | `/search` | JQL 대신 `상태:진행중 담당:김찬호 버그` — 칩 빌더와 양방향, 못 알아듣는 입력은 검색어로 보존 |
| AQL (ALM Query Language) | `/search?aql=…` | JQL 문법 + 한국어 필드 별칭(`상태 = 완료`) — 자동완성·실시간 오류 밑줄, 기본 모드와 양방향 번역 |
| 필터 URL 공유 | `/search?q=…` | 검색 상태 전체가 읽을 수 있는 URL — 링크가 곧 필터 |
| 저장 필터 사이드바 상주 | 전역 사이드바 "필터" | 저장 즉시 노출, 원클릭 적용, hover × 삭제. 서버 저장(`/api/alm/me/filters`, 본인 소유만) — 기기를 옮겨도 따라온다 |
| 해결일로 거슬러 찾기 | AQL `resolved` | "언제 끝났나"를 수정일로 어림잡지 않는다 — 해결이 붙는 순간을 저장해 `resolved >= -7d`·`ORDER BY resolved DESC`가 선다 |
| 정직한 템플릿 미리보기 | `/projects/new` | 카드 미리보기 데이터 = 실제 적용 로직과 같은 파일 |
| 샘플 온보딩 | 생성 템플릿 | 첫 화면이 비지 않게 삭제 가능한 더미 이슈 자동 세팅 |
| 단순한 시간 추적 | 이슈 상세 | 지라 3값 대신 예상+기록 2값 — 진행률 바 하나, 초과는 danger |

- **B2 미리보기(Space)** — 목록(커서)·보드·백로그(포커스·마우스가 가리킨 이슈). 오른쪽 비모달 패널(`IssuePeek`, `role=complementary`)이라 j/k·↑↓로 이웃 이슈, Enter로 상세, Esc·Space로 닫기. 포커스된 버튼·링크의 Space·Enter는 가로채지 않는다(`activatesFocusedControl`). 백로그 행은 Enter만 연다(Space는 미리보기).
- **B3 우클릭 메뉴** — DS `ContextMenu`. 목록 행·보드 카드·백로그 행. 상태·담당자·우선순위·라벨 하위 메뉴(체크 표시), 나에게 할당, 키/링크 복사, 복제(단건), 삭제(확인 창). 고른 이슈 중 하나를 우클릭하면 "n개 이슈" 머리글로 선택 전체에 적용. 이슈 밖 우클릭은 브라우저 기본 메뉴. Shift+F10·메뉴 키도 같다.
- **B4 보드·백로그 다중 선택** — ⌘/Ctrl+클릭 토글, Shift+클릭 범위(보이는 순서), `x` 토글, Esc(미리보기 먼저 닫고 그다음) 해제. 선택 바("n개 선택" · 대량 변경 · 삭제)는 목록과 같은 `대량 작업` 툴바, 대량 변경은 기존 `BulkEditModal` → `bulkUpdateIssues`. 목록은 체크박스와 같은 선택 상태를 쓴다(⌘/Shift 클릭·x가 체크박스를 움직인다). 선택한 카드 여러 장을 한 번에 끌어 옮기기는 하지 않았다(다음 후보).
- **B5 속성 단축키** — 목록·보드·백로그에서 `s`/`p`/`a`/`l`이 팔레트를 그 필드 페이지로 연다(라벨 페이지는 없는 라벨을 검색어로 새로 붙인다), `i`는 나에게 할당. 상세는 `s`/`p`가 상태·우선순위 선택을 펼친다(기존 `a`/`l`과 같은 규칙). `?` 도움말에 "목록·보드·백로그"·"이슈 속성" 묶음을 더했다.
- **낙관적 업데이트** — 메뉴·팔레트·단축키의 필드 변경은 화면에 먼저 반영하고(`patchIssueLocally`), 실패하면 그 이슈만 되돌린 뒤 이유를 토스트로 알리고, 끝나면 스토어 기준으로 다시 읽는다(`useIssueActions`). 단건도 일괄 API(전환 규칙·버전 검사·실패 분리 보고)를 그대로 쓴다 — **새 스토어 함수 없음**.
- **스켈레톤** — 페이지·목록 로딩 스피너를 DS Skeleton으로(`components/Skeletons.tsx`): 셸(상단바 48 + 사이드바 240·항목 32 — AuthGate·OrgAccountGate·App 첫 로딩), 보드(컬럼 4 × 카드 3), 백로그(패널 2 × 36px 행 5), 가젯 판 4개(대시보드 보기 100vh 버그 해소), 타임라인 520px 블록, 이슈 목록 첫 조회는 DS `Table loading` 10행(이름 "이슈 목록 (불러오는 중)"), 지연 로드 화면은 `LazyPage skeleton` prop. 영역 하나가 `role=status` + 접근 이름으로 알린다(스피너 시절 이름 계약 유지). 버튼 안·인라인 갱신 표시는 스피너 유지. 텍스트형 로딩 3곳은 `role=status`.
- **DS 0.14.0 정리** — 옵션 많은 Select에 `searchable`(담당자·프로젝트·스프린트·수정 버전·상위 항목·대상 이슈·리뷰어·직원·프로젝트 리더·추가할 사용자), 필터 줄 입력은 `size="compact"`(32px, 버튼과 같은 높이), 목록 "모두 선택"은 `indeterminate`, Select `min-width:0` 덮어쓰기 제거.
